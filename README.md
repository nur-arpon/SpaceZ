# SpaceZ

The SpaceZ studio website: https://nur-arpon.github.io/SpaceZ/

SpaceZ designs, builds and publishes websites, Windows apps and Android apps. Founded by [Nur Ifran Arpon](https://nur-arpon.github.io/).

Plain HTML, CSS and JavaScript, served by GitHub Pages from the repository root. Motion by GSAP with ScrollTrigger and Lenis (in `assets/js/vendor`). The "Start a project" form (`assets/js/brief.js`) only writes a WhatsApp message; nothing is sent or stored by the site.

`privacy.html` and `404.html` are built from `tools/pages/` with `python tools/build_pages.py`.

Fonts: Inter, Outfit, Fraunces and Cormorant Garamond, under the SIL Open Font License (`assets/fonts`).
